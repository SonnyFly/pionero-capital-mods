## 🇩🇪 Deutsch

### Mod Manager
Mods mit ein paar Klicks installieren, einstellen und wieder entfernen.
- 🔍 Findet das Spiel automatisch über Steam
- 📦 Mods als ZIP hinzufügen (auch per Drag & Drop auf die EXE)
- ☑️ Mods per Haken an/aus → **Übernehmen**
- ⚙️ Einstellungen mit Live-Vorschau direkt im Manager
- 🛡️ Original wird gesichert – „Alle deaktivieren“ stellt das Spiel wieder her
- 🆕 Erkennt Spiel-Updates – ein Klick und die Mods sind wieder drin
- 🌐 Deutsch & English

### Installation
1. `PioneroModManager.zip` herunterladen und irgendwo entpacken.
2. `PioneroModManager.exe` starten (beim ersten Start ggf. SmartScreen: *Weitere Informationen → Trotzdem ausführen*).
3. Gewünschte Mod-ZIPs herunterladen → im Manager **➕ Mod hinzufügen** → Haken setzen → **Übernehmen**.
4. Spiel starten. Das Spiel dabei immer geschlossen haben, wenn du Mods übernimmst.

### Die Mods
| Mod | Was sie macht |
|---|---|
| 📦 Lagerist-Level-Mod | Lageristen füllen je nach Skill-Level mehr Regale auf (Standard 4 / 6 / 8) |
| 🔨 Hersteller-Level-Mod | Hersteller stellen je nach Skill-Level mehr Artikel gleichzeitig her (Standard 3 / 5 / 7) |
| 🎓 Kurs-Mod | Preis und Dauer aller 18 Mitarbeiter-Kurse in % einstellbar |
| 💰 Gehaltskonto-Mod | Schluss mit der „Faulheitssteuer“: Lohn-Limit anheben oder abschaffen |

Alle Werte sind im Mod Manager einstellbar, alle Mods sind miteinander kombinierbar.
Zurück zum Original: im Manager **Alle deaktivieren** oder in Steam *Dateien auf Fehler prüfen*.

## 🇬🇧 English

### Mod Manager
Install, configure and remove mods with just a few clicks.
- 🔍 Finds the game automatically via Steam
- 📦 Add mods as ZIP files (drag & drop onto the EXE works too)
- ☑️ Toggle mods with a checkbox → **Apply**
- ⚙️ Mod settings with live preview right inside the manager
- 🛡️ Original files are backed up – “Disable all” restores the vanilla game
- 🆕 Detects game updates – one click and your mods are back
- 🌐 English & German (switch in the top right corner)

### Installation
1. Download `PioneroModManager.zip` and extract it anywhere.
2. Run `PioneroModManager.exe` (on first start Windows SmartScreen may appear: *More info → Run anyway*).
3. Download the mod ZIPs you want → in the manager **➕ Add mod** → tick it → **Apply**.
4. Start the game. Always close the game before applying mods.

### The mods
| Mod | What it does |
|---|---|
| 📦 Stocker Level Mod | Stockers restock more shelves depending on their skill level (default 4 / 6 / 8) |
| 🔨 Crafter Level Mod | Crafters produce more items at once depending on their skill level (default 3 / 5 / 7) |
| 🎓 Course Mod | Adjust price and duration of all 18 employee courses in % |
| 💰 Paycheck Mod | No more “lazy tax”: raise the unclaimed paycheck limit or remove it |

All values can be changed in the Mod Manager, and all mods work together.
Back to vanilla: **Disable all** in the manager, or *Verify integrity of game files* in Steam.
